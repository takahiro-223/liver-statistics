# EDD フィードバック（ランキング表の作成機能の追加）

**修正契機:** BRD 4.6・PRD（US-08・4.6）の確定を受けた EDD の更新（3.4・5.5・5.8・5.9 の追加）（要求日: 2026-11-23）

## 指摘事項

### No.4
**指摘:** （記載粒度・構成の適切性）ランキングの実装を、`export/` に同居させず、新しいパッケージ `ranking/`（`calc.py` = 算出の純粋関数、`csv_writer.py` = CSV の書き出し、`service.py` = DB 読み取りと全体の統合）として設計した。`export/csv_exporter.py` に足す案もあるが、ランキングは「2 時点の比較・順位付け」というロジックを持つため、分けた方がテストしやすい。この構成でよいか確認したい（推奨: 新設）。
**回答:** 推奨どおり
**ステータス:** 完了

### No.5
**指摘:** （PRD との整合性）PRD の「同順位の並びはユーザ名（正規化後）の昇順」を、`name_key` を Python の文字列比較（コードポイント順）で並べる設計にした。この場合、日本語の並びは五十音順にならない場合がある（ひらがな → カタカナ → 漢字の順で、濁音・半濁音は清音と別の位置になる）。五十音順にするには、読み仮名の情報が必要で、読み取った名前には無い。順位は同じで、同順位の見た目の並びだけの違いなので、決定的に並ぶコードポイント順でよいか確認したい（推奨: コードポイント順）。
**回答:** 推奨どおり
**ステータス:** 完了

### No.6
**指摘:** （PRD との整合性）CSV の先頭行（期間と「各種ランキング」）は、イメージ図では 12 列にまたがる結合セルだが、CSV には結合セルが無い。設計では、1 行目を 1 セルだけ（左端）にして、2 行目以降を 12 列とした。表計算ソフトで開くと、左端のセルの文字が右へはみ出して表示される。12 列すべてに空セルを並べる案もあるが、行の列数が揃うだけで見た目は変わらない。1 セルでよいか確認したい（推奨: 1 セル）。
**回答:** 推奨どおり
**ステータス:** 完了

### No.7
**指摘:** （BRD・PRD との整合性）前回の記録の突き合わせは、`member_id` で行う設計にした。取り込み時に、ユーザ名・別名でメンバーが統合されているため、別名で統合済みのメンバーは同一メンバーとして上昇値が出る。一方、誤読名が別メンバーのまま（訂正前）なら「前回なし」になる（BRD 7・PRD 4.6 の運用上の注意と同じ）。ユーザ名での突き合わせ（表示名の一致）にはしない。この設計でよいか確認したい（推奨: member_id）。
**回答:** 推奨どおり
**ステータス:** 完了
