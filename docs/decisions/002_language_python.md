# ADR-002: 開発言語に Python を採用する

## ステータス

採用

## 背景

画像の読み取り（OCR・画像処理）、データベース登録、CLI を、ローカル環境の単一ユーザー向けバッチとして実装する。言語が未設定だったため選定が必要。

## 決定内容

Python 3.14 を使用する。依存ライブラリ（OpenCV など）が 3.14 に対応していない場合は、3.13、3.12 の順にバージョンを下げて検討する。依存関係は `pyproject.toml` で管理する。

## 理由

| 候補 | 評価 | 採否 |
|---|---|---|
| Python | OpenCV・Pillow・Tesseract ラッパーなど画像処理・OCR のライブラリが豊富。標準ライブラリに `sqlite3`・`argparse` があり依存が少ない。プロジェクト構成ルール（`pyproject.toml`、`config.py`）が Python を前提としている | 採用 |
| Node.js | OCR・画像処理のローカル向けライブラリが Python より少ない | 却下 |
| Go / Rust | 配布・性能面で利点があるが、週次・数十人規模のバッチには過剰で、画像処理ライブラリの選択肢が限られる | 却下 |

## 影響・トレードオフ

- 開発速度とライブラリの豊富さが得られる。
- 3.14 は新しいため、OpenCV など一部ライブラリのビルド済みパッケージが未提供の場合がある。環境構築時に確認し、対応が取れない場合はバージョンを変更する（`requires-python` と本 ADR を更新）。
