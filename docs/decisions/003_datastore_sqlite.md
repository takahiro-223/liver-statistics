# ADR-003: データストアに SQLite を採用する

## ステータス

採用

## 背景

利用者は運営者1人で、データ量は「最大50人×複数部族×週1回」と小さい。ローカル完結の運用であり、サーバーの管理は避けたい。

## 決定内容

SQLite（Python 標準ライブラリ `sqlite3`）を使用する。DB ファイルは `data/` 配下に置き、git 管理外とする。

## 理由

| 候補 | 評価 | 採否 |
|---|---|---|
| SQLite | サーバー不要で単一ファイル。バックアップはファイルコピーで済む。直接書き換え（PRD 4.3 の訂正運用）も標準的なツールで行える。トランザクション・外部キー・UNIQUE 制約が使える | 採用 |
| PostgreSQL | 多人数・同時アクセスに強いが、サーバー運用が必要で今回の規模に過剰 | 却下 |
| CSV / Excel | 重複防止や履歴の参照、トランザクションの担保が困難 | 却下 |

## 影響・トレードオフ

- 構成が簡単になり、バックアップが容易になる。
- 同時書き込みには弱い。複数管理者や Web 画面化を行う場合は RDBMS への移行を再検討する（EDD 8章）。
- インテグレーションテストは、テスト用の一時 SQLite ファイルで実際の DB を使って行う。
