# BRD レビュー観点

このファイルは **BRD (Business Requirements Document) のレビュー時に確認すべき観点**を定めたファイルです。
BRD のレビューを行う際は、以下の観点をすべて確認してください。

---

## レビュー観点

### 1. スコープの明確性
実装したい内容について、**スコープ対象・対象外**が明確に定義されているか。
- 今回対応する機能・範囲が明示されているか
- 意図的に対応しない機能・範囲が明示されているか
- スコープの境界が曖昧な箇所がないか

### 2. 背景・目的の明確性
**プロジェクトの背景・目的**が明確に記載されているか。
- なぜこのプロジェクトが必要なのかが説明されているか
- 解決しようとしている課題が具体的に記載されているか
- 目的が達成可能かつ測定可能な形で表現されているか

### 3. 完了条件の網羅性
プロジェクト完了時に**何ができるようになっているか**が、漏れなく記載されているか。
- 完了の定義 (Definition of Done) が明記されているか
- 期待される成果物・機能がすべて列挙されているか
- 利用者視点での完了イメージが具体的に記載されているか

### 4. 課題・拡張性の記載
**次回修正時の課題や将来的な拡張性**が記載されているか。
- 今回のスコープ外として持ち越した課題が記載されているか
- 将来的な機能拡張の方向性・余地が示されているか
- 既知の制約・技術的負債が明記されているか
