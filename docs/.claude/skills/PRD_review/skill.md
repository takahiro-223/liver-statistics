# PRD レビュー観点

このファイルは **PRD (Product Requirements Document) のレビュー時に確認すべき観点**を定めたファイルです。
PRD のレビューを行う際は、以下の観点をすべて確認してください。

---

## レビュー観点

### 1. BRD との整合性
**BRD に記載されている内容と矛盾している箇所がないか**。
- PRD の目的・スコープが BRD の内容と一致しているか
- BRD で定義されたスコープ対象外の内容が含まれていないか
- BRD の背景・目的と相反する記述がないか

### 2. ユーザーストーリーの明確性
**ユーザーストーリーが明確に定義されているか**。
- 「誰が・何をしたい・なぜか」の形式で記載されているか
- 想定するユーザー・ペルソナが具体的に示されているか
- 各ユーザーストーリーに対する受け入れ条件が明記されているか

### 3. 機能要件・非機能要件の網羅性
**機能要件・非機能要件が、BRD に記載されている内容をすべて満たしているか**。
- BRD に記載されたすべての完了条件が機能要件として反映されているか
- 性能・セキュリティ・可用性などの非機能要件が定義されているか
- 機能要件と非機能要件の間に矛盾や抜け漏れがないか
